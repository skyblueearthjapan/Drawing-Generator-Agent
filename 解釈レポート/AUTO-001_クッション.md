## 1. 3D計測(SolidWorks 2023・読み取り専用インポート)

| 項目 | 値 |
|---|---|
| bbox | X[-12.5, 12.5] / Y[-12.5, 12.5] / Z[0, 27] (mm) |
| 外形 | 25.000 × 25.000 × 27.000 |
| 体積 | 15668.039 mm³ |
| ボディ数 / 面数 | 1 / 11(平面6・円筒4+α) |
| 円筒面 | φ9.5(軸=Z・z=15〜27・半割2面)、φ5.5(軸=Z・z=0〜15・半割2面) |
| 平面 | 25□の側面4面 / z=0面(面積601.242=625−π/4·5.5²) / z=27面(面積554.118=625−π/4·9.5²) / z=15の環状段面(面積47.124=π/4·(9.5²−5.5²)) |
| 円エッジ | φ9.5 @z=15,27 / φ5.5 @z=0,15(いずれも軸線 x=0,y=0) |
| 面取り・フィレット | **無し**(円錐面・トーラス面0) |

体積検算: 625×27 − π/4·5.5²·15 − π/4·9.5²·12 = 15668.1 mm³(SW実測と一致)。

**読み取れた形状**: 25□の角材を長さ27に切り出し、**中心に段付き通し穴**。
z=27側からφ9.5を深さ12(ザグリ)、その先はφ5.5が15だけ続いて反対面へ抜ける。
φ9.5はM5六角穴付ボルトの標準ザグリ径(頭φ8.5)に一致し、**深さ12は頭高さ5に対して過大**
= ボルト頭を当たり面から十分に退避させる意図 → **z=27面が衝撃を受ける当たり面**と解釈した。

## 2. 形状クラス判定

`engine/view_orient.classify` の判定順で追うと:

- 主軸 = Z(円筒面積617.3mm²/全面積4519.8mm² = 13.7% ≥ 10%)
- 旋盤物(lathe)ではない: 直交2辺は25/25で等しいが、**最大同軸径φ9.5 < 0.95×25=23.75** なので
  「外径円筒が断面を占める」条件を満たさない
- 板物(plate)ではない: 最小辺/中間辺 = 25/25 = 1.00 ≥ 0.5
- → **holed_block(穴軸物)** = 「板でも旋盤物でもないが支配的な円筒軸(穴)がある角物」

## 3. 正面ビューの選定(確定戦略の実演)

CLAUDE.md「正面ビュー選定の確定戦略」に従い、**形状クラス別の事前分布順に上位6候補を投影 → PNG化
→ AIオペレータが目視で1つ選ぶ**。候補コンタクトシート: `調査/phase5_ai_operator/cand_1-18.png`

| 候補 | SWビュー+紙面内回転 | 見え方 | 事前分布 |
|---|---|---|---|
| **C1** | `*正面` +0 | 25□の輪郭 + 同心円φ9.5/φ5.5 | 全体1位 56%(plate/holed_blockでは65〜67%) |
| C2 | `*右側面` +0 | 27×25の長方形 + 段付き穴の隠れ線(穴軸=水平) | 累積72% |
| C3 | `*平面` +0 | 25×27の長方形 + 段付き穴の隠れ線(穴軸=垂直) | 累積78% |
| C4 | `*平面` +270 | C2と同じ見え方(X/Y対称のため) | 累積82% |
| C5 | `*正面` +270 | C1と同じ見え方(正方形+同心円のため区別不能) | 累積86% |
| C6 | `*平面` +90 | C2の左右反転 | 累積90% |

**選択 = C1(`*正面` +0 / ex=+X, ez=+Z)**。理由:

1. **形状を最も明瞭に表す**(JIS B 0001 の正面図選定の第一原則)。C2/C3/C4/C6 はどれも
   「featureless な長方形+隠れ線」で、**この部品が丸物でなく25□の角物であることが読み取れない**。
   C1 だけが外形(正方形)と穴径(φ9.5/φ5.5)と同心性を1ビューで同時に示す。
2. **加工基準面が正面に来る**。当たり面=ザグリ側(z=27面)を手前に見る向きであり、
   穴あけ・ザグリ加工はこの面を基準に行う。JIS「加工時の姿勢に一致させる」に沿う。
3. **穴注記(キリ+ザグリ)は円が見えるビューに置くのが原則**。主注記を正面図に置ける。
4. 事前分布でも holed_block の第1候補(65〜67%)。1〜4が全て同じ向きを指した。

補助ビュー(`view_orient.view_plan` が第三角法で自動決定):
`top = *平面+0` / `right = *右側面+0` / `iso = *等角投影`。深さ方向の寸法は right へ回る。

## 4. 寸法設計の考え方(3D計測値のみから)

**設計原理**: ①機能・加工・検査の基準から入れる ②重複させない ③加工工程の順に読めるようにする。

加工工程を「25□角材を長さ27に切る → z=27面からφ9.5を12ザグリ → φ5.5で貫通」と読み、
その順に寸法が読めるよう配置した。

| ID | 値 | ビュー/配置 | 意味・基準 |
|---|---|---|---|
| `W25_x` | 25 | front 下1段目 | 素材幅(モデルX)。基準=角材外形 |
| `H25_y` | 25 | front 左1段目 | 素材高さ(モデルY)。**X/Y両方入れて「25□」を確定させる**(角材の向き取り違え防止) |
| `L27_z` | 27 | right 下1段目 | 全長(突切り寸法) |
| `N_hole` | `５．５キリ　ザグリ%%c９．５深さ１２` | front からの引出線 | 段付き穴を1注記で完結。加工方法(キリ)を残す自社流儀 |

**意図的に入れなかったもの**:
- **φ5.5部の長さ15** … 27−12 で導出できる(JIS: 寸法を重複させない)。
- **穴の位置** … 25□の中心にあり、対称軸上。中心線と外形25で一意に決まると判断した。
  → **§7の採点でここが人間との最大の差になった**(後述)。
- **公差** … 3Dモデルは公差情報を持たず、機能面(はめあい・当たり面の精度)を推定できないため
  方針どおり付けていない。ボルト通し穴φ5.5の公差要否は質問票へ。

## 6. 質問票(要確認事項)

1. **材質**(最重要): ウレタンゴム系か、MCナイロン等の樹脂か、金属か。硬度指定(ショアA/D)の要否。
   → 材質が変わると重量・注記・公差方針が変わる。
2. **個数**。
3. **穴の位置公差 / 穴の面取り**: φ5.5通し穴の位置は「中心」でよいか、位置公差の指定は要るか。
4. **当たり面(z=27面)の面精度・表面性状**の指定要否。
5. **塗装・表面処理**の要否(樹脂なら不要と推定)。
6. ザグリ深さ12は「頭の退避量」として意図的か(標準ザグリ深さより深い)。

### 7-4 差異の自己分析

**(a) 人間が入れてAIが入れなかった `12.5` × 2 — なぜ必要か**

穴の中心位置である。AIは「25□の対称中心にあるから中心線で一意」と判断したが、
**図面は「見た目で中心」を仕様にしてはいけない**。人間は下辺→中心線→上辺を12.5+12.5で明示し、
同時に穴が中心にあることを数値で保証している(全体25とは冗長になるが、これはCLAUDE.md記載の
「人間図面は必ず1本の冗長寸法を含む」に一致する)。
→ **AIの不足であり、人間が正しい。**
ゲート②は対称軸ルール(判定モデルの(d))でこれを合格にしてしまった。
**改善案: 「対称軸上のフィーチャーは、対称記号か位置寸法のどちらかを必ず要求する」ルールを
ゲート②へ追加する**(現状は幾何が一意に決まれば合格=製図としての明示性を見ていない)。
なお人間もX方向の12.5は入れておらず(中心線のみ)、方向の扱いは人間側も非対称である。

**(b) 人間が入れてAIが入れなかった `12`(ザグリ深さ) — なぜ必要か**

注記の`深さ１２`と重複しており、JISの「寸法は重複させない」に照らせばAIの省略が正しい。
一方で人間は**深さが見えているビュー(右側面図)に実寸法として再掲**しており、
ザグリ加工中に段の位置を図から直読できる。**自社流儀としてはAIの不足**と判定する。
→ **改善案: 穴注記に`深さ`を含む場合、その深さが見える輪郭ビューにも寸法を再掲する**
(冗長だがゲート②は冗長を警告どまりにしているので支障ない)。

**(c) AIが入れて人間が入れなかった寸法 = 0本。** 過剰は無かった。

**(d) 注記の表記が違う — `%%c５．５`(人間・φ表記) vs `５．５キリ`(AI・キリ表記)**

2026-08-09の裁定は「キリ表記が既定」だったが、**この部品の人間図面はφ表記**だった。
コーパスに両方が実在する(=部品/作図者により揺れる)ことの実例。数値・構成
(径→ザグリ→深さ)・`%%c`制御コードの使い方は完全一致しているため、**表記の切り替えは
`dim_engine.HOLE_NOTE_DEFAULT` の1定数で済む**。→ ディレクター裁定の再確認事項として質問票へ。
