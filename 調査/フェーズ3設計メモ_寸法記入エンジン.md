# フェーズ3設計メモ: 寸法記入エンジン(ディレクター起草・v0)

> フェーズ1(図枠)・フェーズ2(SWビュー投影)の完了後に着手する最難所。
> 本メモは分析の観点を先に固めておくための設計書。結果に応じて改訂する。

## 目標

「加工者・材料調達者が電卓を叩かずに作れる」寸法・注記の入った部品図を、
AIの作図計画+決定論的な配置エンジンで生成する。

## 分析ステージ(参考200組からの流儀抽出)

各部品図DXFについて、以下を機械抽出して統計を取る(担当: Sonnet想定):

1. **ビュー構成**: 部品の形状クラス(板物/旋盤物/曲げ物/溶接構造)ごとに、
   何ビュー使うか(正面のみ/正面+側面/三面図+詳細図)、断面図・矢視図の使用頻度
2. **寸法の種類と密度**: DIMENSIONのタイプ別(長さ/直径/半径/角度/座標)本数、
   1部品あたり寸法数の分布
3. **基準の取り方**: 寸法の測定点が部品のどの縁(端面・中心線・穴中心)に集まるか。
   片側基準(累進)か中央基準か
4. **穴の注記書式**: 「4-φ9」「M6」「PCD」等の表記パターン(MTEXT/引出線)を正規表現で収集
5. **公差・仕上げ**: ±公差の付く寸法の特徴(嵌合径・ピッチ)、仕上げ記号(▽)の使われ方
6. **配置ルール**: 寸法線のビューからの距離、寸法同士の間隔、文字高さ、矢印スタイル
7. **注記**: 図面ごとの共通注記(「塗装色は工番指定色」等)の出現パターン

## 作図計画フォーマット(案・JSON)

AIオペレータが出力し、配置エンジンが実行する中間表現:

```json
{
  "part": {"model": "...", "図番": "...", "品名": "...", "材質": "SS400", "個数": 2},
  "shape_class": "板物",
  "views": [
    {"id": "front", "sw_view": "*正面", "position_hint": "center-left", "scale": 1.0}
  ],
  "dimensions": [
    {"view": "front", "kind": "linear|diameter|radius|angle",
     "from": {"type": "edge|hole_center|centerline", "model_ref": "..."},
     "to": {...}, "value_expected": 150.0, "tol": null, "placement": "below|left|..."}
  ],
  "hole_notes": [
    {"view": "front", "pattern": "4-φ9", "holes": [[x,y],...], "leader_from": [x,y]}
  ],
  "annotations": ["塗装色は工番指定色とする。"]
}
```

- `value_expected` は**AIの読解値**。配置エンジンは実ジオメトリから実測して寸法値を入れ、
  期待値と食い違ったらエラーにする(=ゲート①を作図時から内蔵)

## 配置エンジン(ezdxf側)

- 図枠テンプレート+SWビューDXF+作図計画JSON → 最終DXF
- 寸法はezdxfのDIMENSIONエンティティで生成し、DIMSTYLEは参考DXFから採取したものを使用
- 衝突回避(寸法同士・ビューとの重なり)は決定論的なレイアウトルールで解く
